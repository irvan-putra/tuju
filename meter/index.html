Journey meter

Time a ride and, if you want, measure its distance with GPS, then compare with what the operator's data says for the stops you picked: scheduled minutes and straight-line stop-to-stop distance where the official GTFS feed covers the leg, an honest not measured where it does not - no invented figures. Everything runs on this device: this screen makes no network calls, sends nothing and stores nothing. The timer works without GPS. GPS stays off unless you switch it on - the location permission is asked only then - and it tracks only while this screen is open; leaving or closing the screen stops it.
